# Project Title

Building  First Node.js HTTP Server

---

# Objective

The objective of this lab is to learn how to create a basic HTTP server using Node.js. This project demonstrates how to handle multiple routes, return plain text and JSON responses, use environment variables for the server port, and manage unknown routes with a 404 response.
